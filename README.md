# Guitare — Progressions d'accords

Outil web interactif pour composer et improviser à la guitare :

- **7 styles** : Rock, Blues, Metal, Pop, Jazz, Folk/Country, Funk/Soul
- **Bibliothèque de progressions** classiques par style (I–IV–V, vi–IV–I–V, blues en 12 mesures, i–VI–VII métallique, ii7–V7–Imaj7…)
- Clique directement sur une progression pour la charger, ou lance l'**aléatoire** pour t'entraîner
- **Accords avec doigts** : premier fretboard montrant l'emplacement des doigts (1–4), fondamentale en rouge, + diagramme d'accord vertical (positions standard formes Mi/La, power chords)
- **Lecteur** : navigation précédent/suivant (ou par degré), flèches, tempo réglable (40–220 bpm), temps par accord (1/2/4), lecture automatique qui enchaîne les accords en strum
- **Gammes suggérées** pour improviser : le second fretboard affiche la gamme compatible (majeure, modes, mineures, pentatoniques, blues), fondamentale en rouge, notes de l'accord en cours en jaune
- Audio WebAudio : clique toute note ou diagramme pour l'entendre ; « Séquence complète » joue toute la progression au tempo choisi
- **Métronome** : patterns de batterie synthétisée (Rock, Metal, Shuffle blues, Ballade, Clic), mesure 2/4-3/4-4/4, tempo et volume réglables, indicateur de temps, synchro auto avec le lecteur (ou mode libre)
- **Favoris** : enregistre tes progressions préférées avec leur tonalité et une note perso (stockées dans le navigateur)
- **Plusieurs façons de jouer le même accord** : bouton « Forme suivante » pour cycler entre les formes Mi / La / Ré + voicings partiels (triades cordes 4·3·2 / 3·2·1, basses étouffées)
- **Notes affichées sur le fretboard** : affichage des notes (A, B, C… ou Do, Ré, Mi…) ou des numéros de doigts, au choix
- **Encadré « notes de l'accord »** : nom de toutes les notes jouées avec la tonique mise en avant (ex. Mi mineur : « Mi, Sol et Si (E, G, B) »)
- **Thème clair ou sombre** : réglage persistant dans le navigateur
- Style **Shoegaze** : mur de son, voiles Imaj7–IVadd9, rêverie, nappes, réverb I–vi–IV–IV, brume i–VII–VI–VII
- **Progressions supplémentaires** inspirées du recueil *Progressions Classics Vol. 1* (Jeffrey Kunde) : les 3 familles classiques (I–vi–IV–V, I–V–vi–IV, I–IV–V) déclinées, Pachelbel pop I–vi–iii–IV et canon I–V–vi–iii–IV, turnarounds, escaliers jazz
- **Accords vérifiés jouables** : audit automatique — aucun accord ne demande plus de 4 doigts (Fa add9 corrigé)
